# Hermes + Herdr Blueprint

Recreates the working Hermes coding-agent setup on an exe.dev/Linux box:

- Hermes Agent using an existing OpenAI Codex/ChatGPT subscription
- Browser Use CLI backed by persistent headless Chromium
- Hermes skill/tool search enabled
- Hermes registered with Herdr for lifecycle detection
- An authoritative local Herdr skill generated by the installed `herdr` binary
- Hermes messaging guidance that distinguishes transport ACKs from typing, interim commentary, and three-minute long-turn status

## Quick start

```bash
./scripts/install.sh
hermes model
./scripts/verify.sh
```

During `hermes model`, choose **ChatGPT or Codex Subscription** and the desired Codex model. Existing `~/.codex/auth.json` credentials can be explicitly imported, but the blueprint never copies or commits credentials.

See [`BLUEPRINT.md`](BLUEPRINT.md) for architecture, recovery, and manual steps.

## Security

Do not commit any of these files:

- `~/.codex/auth.json`
- `~/.hermes/auth.json`
- `~/.hermes/.env`
- agent credential directories

The repository contains configuration procedures only—no tokens or account data.
